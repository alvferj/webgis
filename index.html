Painel WebGIS - Gestão de Plantios

Gráficos Dinâmicos (Plantios)

Análise Temporal (Estilo SATVEG)

Clique em um Polígono de Área no mapa para gerar a série temporal de NDVI.

Dica de Navegação: Clique nos pontos laranja no mapa para ver os detalhes de cada plantio.

Nota sobre NDVI/NDWI: O visualizador de imagens e o gráfico SATVEG utilizam uma API de demonstração (Sentinel Hub). Se as imagens ficarem cinzas ou não carregarem, o limite diário gratuito esgotou. Será necessário inserir sua própria chave de API WMS no arquivo index.html.

Nota sobre Mapa de Fundo: Foi incluída a imagem de satélite de alta resolução da Esri e OpenStreetMap.
